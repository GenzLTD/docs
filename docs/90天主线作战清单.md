## 四、PG schema 文件复用说明

**`genzltd_schema_v0.2.sql` 完整无损，50 张表定义齐全**（users / user_identities / game_profiles / trust_memories / trust_attestations / share_codes / verification_audit_log / timeline_events / enterprises / candidates / match_reports / orders / subscriptions / poems 等，对齐 manager.py 真源），随时一条命令重建 PG：

```powershell
# 连接凭据经 pgpass 或交互输入，勿在文档/代码中明文存放
psql -U postgres -h localhost -p 5432 -d postgres -c "CREATE DATABASE genzltd;"
psql -U postgres -h localhost -p 5432 -d genzltd -f "<本机 schema 路径>/genzltd_schema_v0.2.sql"
```

**定位**：蓝图参考，融资期不投精力维护；融资后若要迁 PG，直接复用这份文件重建。
