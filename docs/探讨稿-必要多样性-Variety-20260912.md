## 0. 一句话

《新一代智能大脑架构设计》决策⑧ 把认知内核记为「约 80% 是**认知是什么** + 剩余 20% 是**认知偏差检测**」，并自行声明后者「无法纸上谈兵，必须落地运行后逐步补全」。

本稿提出的主张是：**这 20% 之所以不能被事先规定死，不是工程进度问题，而是控制论上的必然**——必要多样性原理（Ashby's Law of Requisite Variety）。若该框架成立，则「补 20%」的正确动作不是「写规格 → 实现」，而是「**先建记录通路 → 让判例积累 → 事后追认规则**」。

需要特别声明：**20% 这个数字本身是假设、是占位符，不是度量。** 本稿讨论的是它标记的那块**容量**，不是它的小数点。

## 1. 缘起

三轮讨论逐步收敛，本稿是该收敛的书面化：

1. **第一轮**：核对多端数据一致性时，问题被表述为「真源在哪」。
2. **第二轮**（owner 纠正）：真源不是「哪张表行数多」，而是**端侧与边侧的校验权限归属**。当前天翼 / 海外 Vultr / 腾讯 / 阿里 四台云机是**阶段一形态**（四台平铺，无角色分层）；目标形态是**端侧天翼 + 边侧仿真**（其余三台作为边缘执行面）。adjudication（裁定权）归端侧；execution（执行自主）归边侧。
3. **第三轮**（owner 定调）：以篮球比赛为喻——**裁判组 ≈ 端侧**（有裁定权，但不跑位、不投篮），**运动员 ≈ 边侧**（跑位与发挥自主，但不能自己吹哨）。并给出关键一句：**「没有任何契约是一成不变的，有裁判权不等于规则契约不能适应时代的要求去变化。」**
4. 落到《架构设计》决策⑧ 的 20% 缺口上，owner 的判断是：**「20% 是长期实践跑出来的结果，而不是事先规定死的」**；**「道路且长且远，但只要方向对，还是值得的」**。

本稿要回答的是：**为什么「不能事先规定死」不是一句姿态，而是一条可以被表述清楚的约束。** 并据此请评审裁定：这个框架是否值得作为认知内核的正式分析语言。

## 2. 框架：必要多样性

> 本节为**外部理论引入**，非本仓既有口径。理论本身有半个世纪以上的积累，此处只取与本文命题相关的部分。

### 2.1 原理

**必要多样性原理**（W. Ross Ashby，*An Introduction to Cybernetics*，1956；常见表述："Only variety can destroy variety"）：一个调节者能够抵消失败结果的程度，受限于它自身可用的**多样性**（variety，即可区分状态的数量）。当被调节系统的可能状态数远大于调节者的可能反应数时，**失控不是操作失误，而是结构性的**——调节者再努力，也无法覆盖它无法区分的状态。

用一句更直白的话：**你不可能用一个有限的规则表，去裁定一个无限的世界。**

### 2.2 控制的两只手

达到"够用"的多样性，只有两条路，且两条路都在实践中被广泛使用：

| 策略 | 做什么 | 典型手段 |
|---|---|---|
| **削减被控系统的多样性**（variety attenuation） | 把世界的可能性**压小**到规则能覆盖的范围 | 标准化、canonical schema、白名单/黑名单、门控、限制入口、拒绝服务 |
| **放大调节者的多样性**（variety amplification） | 把裁定方的**可区分能力**做大 | 增加传感器/判例库、经验积累、学习、**把人放进来**、分级授权 |

Ashby 的要点是：**两者可混合使用**。实践中很少有"纯削减"或"纯放大"的系统；真正的问题是**在什么域上用削减，在什么域上必须靠放大**。

### 2.3 为什么它正好解释了"契约不能预先规定死"

- **规则表是削减手段**：它的效力上界，就是它枚举过的状态空间。
- **现实世界的状态空间**：在系统真正跑起来之前，是**不可枚举**的——你不知道用户会怎么用、数据会怎么脏、协作会怎么变形。
- **因此**：任何试图在开跑之前就把规则写全的契约，都在假设"被控系统的多样性是可预知的"。这个假设在**收敛域**（跨境、隐私、放行这类边界清晰的问题）成立，在**开放域**（认知是否正确、行为是否偏移）不成立。
- **结论**：开放域上的裁定能力，只能靠**调节者一侧的多样性增长**获得——也就是**判例积累**。这正是 owner 那句「有裁判权不等于规则契约不能一成不变」在控制论上的对应物：**裁判权是固定的，判例是长出来的。**

## 3. 用这个框架重读既有资产

> 本节是本文的主要工作：不新增设计，只把**已经存在的决策**放进这个透镜里，看它们是否各就各位。所有引用均给出路径与 Status。

### 3.1 决策⑧ 的双组件 = 两只手

> 引自 `genzltd-docs/docs/新一代智能大脑架构设计.md:174-181`（Status：远景研讨稿，受 ADR-0009 约束）：

```text
### 决策⑧ 认知偏差检测：黑匣子双组件（认知内核的质量保障）
- **命题**：「认知是否正确」与「认知是什么（Layer0/1/2）」是认知内核的两面，缺一不可。世界模型定义认知结构，偏差检测保障认知不漂移。
- **组件① 现场处置校验（实时 · 事前防偏）**：每次行为比对规范（Layer0/1/2 canonical + 门控规则）才放行，对应 `ctx.policy` + zervi-looma 门控。
- **组件② 记录 + 大数据比对（异步 · 事后纠偏）**：完整记录远端声音（感知输入）/ 操作（工具调用）/ 指令（决策），事后与共识数据、历史模式比对，检测认知漂移。
- **务实边界**：...zervi-looma 现有约 80% 是「认知是什么」，剩余 20% 的「认知偏差检测」无法纸上谈兵，必须落地运行后逐步补全。
```

在框架下，这两个组件**不是两件并列的事，而是一只手的两个方向**：

| 组件 | variety 方向 | 实质 |
|---|---|---|
| **组件①** 实时事前防偏（`ctx.policy` + zervi-looma 门控） | **削减** | 每次行为必须先比对 Layer0/1/2 canonical 与门控规则**才放行**——把不许发生的状态挡在门外 |
| **组件②** 异步事后纠偏（黑匣子记录 + 大数据比对） | **放大** | 记录感知输入 / 工具调用 / 决策指令，事后与共识数据、历史模式比对——**增加裁定方可区分的状态** |

**这个读法的价值**：它把「80% / 20%」从一个**进度百分比**，改写成一个**结构说明**——
- 80% = 已经能靠**削减**覆盖的部分（认知结构 + 门控 + 共识评分）；
- 20% = 只能靠**放大**获得的部分（判据、判例、纠偏动作）。
- 前者可以"做出来"，后者只能"长出来"。这也解释了为什么架构文档自己说后者「无法纸上谈兵」。

### 3.2 端 / 边分工 = 调节者与被调节系统（裁判与运动员）

| 篮球 | 本系统 | 在框架中的角色 |
|---|---|---|
| 运动员个体：跑位与发挥自主 | 边侧（执行面） | **多样性的来源**——自主执行必然产生预案之外的场景 |
| 裁判组：有裁定权但不干预执行 | 端侧（权威面） | **必须持有不劣于对方的多样性**，否则哨子吹不准 |

owner 的比喻直接对应 Ashby 的结构：**运动员不被预先规定死，是多样性的供给侧；裁判能吹准，靠的是见过的比赛多，而不是规则书写得厚。** 这也说明了为什么"裁判下场跑位"（端侧替边侧做日常决策）和"运动员自己吹哨"（边侧自裁）都会让系统失效——它们是**两侧多样性的角色错配**，而不是权限大小的争执。

### 3.3 决策⑦ 记忆物理分层 = 多样性的物理分布

> 引自 `genzltd-docs/docs/新一代智能大脑架构设计.md:163-170`：

```text
### 决策⑦ 记忆物理分层：设备 · 边缘 · 场景三层就近分布
- **设备层（穿戴设备）**：工作记忆——当前场景上下文、传感器流，数据不出设备。
- **边缘层（边缘节点）**：情景记忆 + 个人语义记忆——个人完整图谱（实体·边·事件），本地存储，PIPL 合规，断网可用。
- **场景层（云端）**：共识语义记忆 + 程序记忆——脱敏后的共识子图，走 Wukong 门控，用于跨境匹配与共识评分。
- **上浮 / 下沉机制**：数据默认留设备/边缘；仅「需跨场景共识 + 已脱敏」的数据上浮云端。
```

| 层 | 多样性持有量 | 说明 |
|---|---|---|
| 设备层 | 最高（原始、未脱敏、上下文富） | 多样性留在离用户最近处 |
| 边缘层 | 高（个人完整图谱） | 本地存储、断网可用 |
| 场景层 | 低（脱敏后的共识子图） | 上浮即**削减**——脱敏 + 门控就是 attenuation |

**这个读法的价值**：决策⑦ 不只是一条隐私设计，它同时是一条**多样性分布设计**——高多样性就近保存，云端只收已经削减过的共识。这与"端侧权威、边侧执行"是同一个结构的两种说法。

### 3.4 信任层（ADR-0009）= 削减路线 + 人类作为多样性来源

`docs/adrs/0009-trust-layer-over-world-model.md`（**Accepted**）在框架下读起来非常整齐：

| ADR-0009 的决定 | 在框架中的含义 |
|---|---|
| Decision 1：**近期不承诺世界模型大脑**；M3–M6 与「M2 认知内核本体」不作为当前编制的承诺项 | **拒绝走"无限放大调节者"的路线**——编制不足以支撑放大到世界模型 |
| Decision 2：近期只承诺**信任层**，最小集 = 人定口径 / 机执行阀门 / 可拒绝可追溯 / 人类在场 | **改用"削减被控域"**——把问题限定到跨境、隐私、放行规则这些**边界清晰、可枚举**的域 |
| 原话：「同一输入给出同一 verdict」 | 削减的验收标准：**把多样性压成确定性** |
| 原话：「没有人类在场的判定与追责，输出只是或然文本，不能当信任来源」 | **人类是必需的外部多样性供给**——这是放大路线被推迟、但未被取消的证据 |

同一份评审对此的表述，也正好是"现有大脑多样性不足"的诊断：

> 引自 `genzltd-docs/docs/新一代智能大脑-信任层评审-20260907.md:32`：

> 架构 §2 已诊断历史大脑停在「关键词意图 + if-else 分发」。Tatha 今天仍是 5 意图。本周锁住的，是 if 里那张跨境表。

以及那张表的实际状态（同文 `:38`）：

```text
| 认知内核 | 世界模型 + 门控 + 共识 + 偏差 | **只锁门控表** |
```

用框架说：**5 意图枚举 = 调节者多样性远小于开放需求的多样性**，这正是架构 §2 所诊断旧病的控制论名字。

### 3.5 两张表的一次交会：ADR-0009 与决策⑧ 是同一件事的两段

| | 近期（ADR-0009） | 长期（决策⑧ 组件②） |
|---|---|---|
| 路线 | **削减** | **放大** |
| 手段 | 门控 / canonical / 固定 verdict / 人在场 | 黑匣子记录 + 判例积累 + 事后纠偏 |
| 状态 | 已 Accepted，且已锁住一片（64 组合） | 未开工，且**明确不是近期承诺** |
| 关系 | 在**受限域**内先拿到确定性 | 是**日后扩大受限域**的唯一正当通道 |

**这是本稿最核心的一句**：20% 不是"还没做完的 20%"，而是"**日后能不能合法扩容的 20%**"。没有它，系统只能维持在已经削减好的那几个域里；有了它，规则契约才可能随时代变化——而那条变化通道**必须是判例驱动的，不能是拍脑袋驱动的**。

## 4. 20% 为什么是占位符，而不是待补清单

| 常见误读 | 框架下的问题 |
|---|---|
| 「20% 是没写完的功能，补齐即可」 | 开放域的多样性不可在开跑前枚举；把它当功能清单，等于假设世界可预知 |
| 「用更强的模型可以填上」 | 模型是**外部供给**，不提供**口径、拒绝权、追责主体**。该判断与 ADR-0009 一致（「把『更强的模型』写成『大脑已至』，是用发布会替换治理」）——本稿只是补了它的控制论依据 |
| 「先把偏差判据定义清楚再实现」 | 判据本身就是**要从案例中归纳的结论**；先定判据 = 先用现有偏见把案例剪裁一遍，之后积累的"判例"会系统性偏 |
| 「补上就等于大脑完成」 | 组件② 是**扩容通道**，不是终点；它使"扩大受限域"成为可能，而不是宣布受限域不存在 |

架构文档自己给出的类比也已经写了同一件事——**航空 FDR/CVR 是几十年才成熟的**，不是设计出来的。本稿认为这个类比应当被当真，而不是被当作免责声明。

## 5. 框架划出的边界：什么可以先定，什么必须长出来

本稿**只划边界，不填内容**。以下左列是 scaffold（工程与权力结构，可以现在定）；右列是判据与结论（只能长出来，**本稿一个字不写**）。

| | **可以先定** | **必须长出来** |
|---|---|---|
| 内容 | 记录什么（黑匣子三路：感知输入 / 工具调用 / 决策指令）；记录在哪（远端记录、中心比对）；**裁定权归端侧** | 偏差的判据；偏差案例的分类；纠偏动作；规则的演化方向 |
| 为什么 | 这是"黑匣子"的物理定义 + 已经拍过的权责分工，不依赖任何经验结论 | 它们**就是**从真实流量里归纳出来的结论 |
| 现在能不能写 | 可以（且不违反 ADR-0009） | **不能**——写了即把猜想伪装成判例 |
| 归属 | 工程 scaffold | 实践产出 |

> 说明：架构文档对组件② 的原话也是先"**搭记录框架**"，再"边跑边积累偏差案例"。本稿认为这个顺序不是"先易后难"，而是**唯一正确的顺序**：没有记录通路，判例无从积累，判据只能靠猜。

## 6. 对组织的含义（探讨点，不作结论）

1. **工程动作的形状会变**。若框架成立，20% 对应的近期可交付物不是"偏差检测模块"，而是**记录通路 + 案例归档格式**这一层 scaffold；判据留白。
2. **时间尺度是"年"，不是"季度"**。这与 ADR-0009「近期不承诺世界模型大脑」完全一致，不构成对它的挑战；本稿只是把"为什么是年"讲清楚。
3. **编制结论不变**。框架不提供任何"用更多人更快做出来"的理由——恰恰相反，它说明这条路的速率上限由**真实流量**决定，而流量的速率不因加人而变快。
4. **风险提示**：把 20% 写成季度交付，就是用"幻想进度"替换"信任进度"（`新一代智能大脑-信任层评审-20260907.md` 原话）。本稿的目的之一，是给这个风险提供一个可复述的理由。

## 7. 本稿明确不做

- **不写 20% 的规格**（判据、分类、纠偏动作、演化方向一概留白）。
- **不改变任何 ADR 状态**（0009 Accepted / 0010 Proposed / 0011 Accepted 均原样）。
- **不把 `variety` 当作已记载口径**——它是本文引入的探讨框架，`docs 未记载`。
- **不承诺任何季度交付物**。
- **不复活** ADR-0009 已冻结的 Agent loop / M3 记忆三层化，**不触碰** ADR-0011 冻结的 dsh-bridle 产品化 / 诗词语料流水线 / 人才 RAG 索引。
