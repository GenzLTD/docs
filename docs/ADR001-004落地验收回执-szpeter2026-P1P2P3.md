## 四、⚠️ 阻塞项：CI 未转绿，需 owner 配 `GENZ_GATE_PAT`

- **现状**：三仓的 `genz-gate` CI run **全部 `failure`**。
- **成功/失败分布**：lab 自己的 `m2-lab-python`（不跨仓）**success**；所有**跨仓** job（`m2-matrix-parity`、`m3-compliance`）在 lab / wukong-core / cortex-mcp 三仓均失败。
- **失败日志根因（已取证）**：
  ```
  remote: Repository not found.
  ##[error]fatal: repository 'https://github.com/GenzLTD/<其他仓>/' not found
  ```
  即跨仓 checkout 失败——Free 私有组织默认 `GITHUB_TOKEN` **无权访问对仓**。
- **判定**：这不是代码 bug，是落地计划 P2 已注明的**前置依赖未满足**——org secret **`GENZ_GATE_PAT`（read 访问 GenzLTD 私有仓）尚未配置**。
- **后果**：在配 secret 并重跑前，genz-gate 尚不能作为「三仓规则漂移硬门禁」生效。

### 待办动作（owner，`zervi-genz`）

- [ ] owner 在 **GenzLTD 组织级** 创建含 `read` 私有仓范围的 secret **`GENZ_GATE_PAT`**
      （workflow 读取处：`env.GENZ_PAT = ${{ secrets.GENZ_GATE_PAT || github.token }}`）
- [ ] 配置后**重跑三仓 genz-gate CI**，确认 `m2-matrix-parity` / `m3-compliance` 转绿
- [ ] 此后该链才真正闭环：`policy_rules.yaml` 变更须三仓全绿方可 promote（ADR-0001/0003 硬门禁）
