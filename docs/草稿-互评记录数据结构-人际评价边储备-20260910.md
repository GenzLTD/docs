# 互评记录数据结构设计 v0 —— 人际评价边立项储备

> 2026-09-10 | 来源分析对象：夏峻《管理能力评价表与行为评价表.doc》
> 性质：**设计输入储备稿**（响应 ADR-0011 纪律：不回写 PR#11，正式立项须新开文档 —— 本文档即按此纪律准备的"新开文档"底稿）

## 1. 源文档解剖（三张表 = 三种评价原语）

| 表 | 机制 | 数据学本质 |
|---|---|---|
| ① 管理能力评价表 | **50 项行为、25 对奇偶强迫选择**（A=正向 2 分 / B=反向 1 分），评价人划 √ + 算分 + 意见 | Forced-choice 量表：每对锚点互斥，天然抑制"全打高分"的中庸偏差 |
| ② 行为与态度考核表 | 5 项目 × 权重（合作20%/学习创新20%/责任感30%/积极性15%/纪律性15%）× 5-1 等级，Σ 加权 | 加权评分卡（weighted rubric） |
| ③ 行为与态度考核量表 | 每项目 1-5 级行为锚点描述（BARS） | 行为锚定等级：等级有客观行为证据标准，非主观印象 |

**25 个管理能力维度**（①表）：理解工作、时间观念、分析判断、归纳总结、计划性、灵活性、思路开阔、任务分配、主见、有始有终、创造力、耐性、危机处理、远见、听取意见、合作意识、表达能力、人际受欢迎、帮助下属、鼓励下属、组织能力、魄力、决策、沟通、责任感。

## 2. 与诗词语料验证的模型对齐

| 诗词沙盘（已验证） | 本量表 | 互评数据结构 |
|---|---|---|
| 送/贈/和 → 某人（**评价边**） | 评价人 → 被评价人（**定向评分**） | `source → target` 有向边 |
| 哭/悼 = 地位公认 | 多评价人汇聚 = 共识 | 同 target 多边聚合 |
| 诗集 = 作品集 | 行为锚点 = 证据标准 | `evidence_refs` 事件锚点 |

## 3. 核心数据结构（`evaluation_edge.schema.v0.json` 配套）

### 3.1 维度层（静态，一次定义）

```
Dimension     { dim_id, name, category: management|attitude,
                weight?,                    // ②表权重，attitude 类必填
                method: forced_choice|bars|weighted_score,
                anchor_pairs?: [{ anchor_a, anchor_b }],   // ①表一对
                bars?: [{ level:1-5, description }] }      // ③表锚点
```

### 3.2 评价边层（动态，每次互评一条）

```
EvaluationEdge {
  edge_id, cycle_id,                       // 评价周期（季度/项目），支持时间轴模型
  source_pseudo_id, target_pseudo_id,      // 伪匿名 ID（映射表物理分离保管）
  source_role: peer|subordinate|superior|self|client,
  instrument_version,
  items: [ { dim_id, choice?: A|B, level?: 1-5,
             raw_score, anchored_text } ],  // anchored_text=命中的行为锚描述（可审计）
  scored: { per_dim: {dim_id: score}, weighted_total? },
  free_text,                               // 评价人意见（入图前过字段级脱敏）
  evidence_refs: [],                       // 可选：事件/文档锚点
  signature,                               // Ed25519，对齐 trust.v1.json attestation
  created_at
}
```

### 3.3 图层（汇聚成"共识"）

```
PeerGraph   节点 = Person(pseudo_id)
            边   = EvaluationEdge 聚合：
                   同 (source,target,dim) 多周期 → 边时间序列
                   同 (target,dim) 多 source   → 维度共识分
声誉信号    共识分 = Σ(各 source 评分 × source_credibility) / 有效评价人数
            source_credibility 由该 source 历史评价的区分度（避免全 A/全 5）动态加权
```

## 4. 五条红线在结构里的落点（继承 PR#11）

| 红线 | 结构落点 |
|---|---|
| 防自证 | `source_pseudo_id != target_pseudo_id` 硬约束；self 边单独存储不计入共识 |
| 图级脱敏 | 伪匿名 ID + 映射表分离保管；`evidence_refs` 只存哈希不存原文 |
| 几何层≠信任 | 共识分只是输入；是否映射 verified/weak/unverified 由 trust.v1.json 状态机消费方决定 |
| 匿名≠不可审计 | 每条边带 Ed25519 签名 + anchored_text 审计线索；审计方可凭映射表反查 |
| 合规 | 入图前过 `desensitize.py` 闸门（字段级），出网片段过白名单审计 |

## 5. 与既有资产的对接点

- `looma-zervi/backend/contracts/trust.v1.json`：EvaluationEdge 签名/attestation 直接复用其 Ed25519 格式；
- `social_bfs.py` / `graph_builder.py`：PeerGraph 聚合可直接挂接现有图构建器；
- `enterprise_routes.py` trust_profile：图层输出即该端点未来的数据源（前端未消费状态正好留出接入位）；
- dsh-bridle 诗词语料：维度标签（合作/欢迎/表达）与评价边动词（和/贈/哭）可做 crosswalk 标定集。
