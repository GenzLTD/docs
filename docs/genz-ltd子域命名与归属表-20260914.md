## 一、命名决策

### 1.1 决策

`genz.ltd`（海外叙事线，YEDALL LIMITED / Stripe）新增子域，命名海外侧**自治小生态**：

- **`edge.genz.ltd`**（边侧）

`edge` 对齐组织既有架构语言「端侧天翼 + 边侧执行面」：adjudication（裁定权）归端侧，execution（执行自主）归边侧（[探讨稿-必要多样性-Variety-20260912.md](探讨稿-必要多样性-Variety-20260912.md) §2.3）。海外 Vultr 属边侧执行面，域名与架构术语同源。

### 1.2 edge 的定位与功能边界

`edge.genz.ltd` 承载的「海外边侧生态」：

1. 对接 Vercel 营销站点（前端）
2. 支持 Stripe（海外支付，YEDALL 沙盒）
3. 凡不依赖天翼端侧契约验证的跨云服务功能，均在 Vultr 边侧落地

对整个 THOMAS 是自治小生态——边侧执行面，执行自主、不碰端侧裁定，与「端侧天翼 + 边侧执行面」分层自洽。
