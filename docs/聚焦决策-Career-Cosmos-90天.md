# Career Cosmos 聚焦决策（90 天）

> 状态：**已决策** · 决策人：szpeter2026 · 日期：2026-09-07
> 一句话：**聚焦一条主线——Career Cosmos 矩阵，为融资服务；其余归档/暂停。**
> 原则：**面向未来，不背历史包袱。聚焦才有力量——聚焦一个产品，好过摊子很大、不挣钱。**

---

## 一、为什么做这个决策

- 团队 **7 人**，同时维护十几条产品线，每一条都是半成品（生产就绪度普遍 50% 上下，认证/DB 是桩、职位库 Mock、三端零测试）。
- 近期唯一硬目标是**深创赛融资 300 万**（出让 5–10%，2026 Q4–2027 Q1）。
- 历史包袱已卸（Wukong 对账、72changes 归档，2026-09-07），现在是收敛的最佳时机。

## 五、决策原则（写给团队）

- 砍线会有阻力——执行者对自己产出的东西天然有「禀赋效应」，会高估自己投入过的部分。这是正常的，不怪谁。
- 但判断标准只有一个：**这件事是否服务于「融资活下来」这条主线。** 不是，就归档/暂停，不拖。
- 归档 ≠ 否定。未来编制或资源到位，随时可以解冻重开。
- **2026-09-09 补充**（[ADR-0011](adrs/0011-dsh-bridle-freeze-career-cosmos.md)，组织 owner `szjason72` Accepted）：结束 dsh-bridle 产品化争论。诗词语料流水线与人才 RAG 索引不是下一场战役。编制回到上表四块拼图与第 1–5 条硬动作。bridle 仅作各人本机口径适配器：回答组织问题前必须同步本仓 `origin/main` 再检索；说不出 SHA / 路径 / Status 即视为瞎说。信任层走 Wukong 门控 + `genz-verify`，不以聊天记录代替本仓口径。
